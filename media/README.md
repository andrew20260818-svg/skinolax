# Картинки товара

Исходники упаковок и витринных картинок. Сайт их напрямую не использует: `npm run images` (сам вызывается в `npm run dev` и `npm run build`) делает из них готовые файлы в `public/assets/media/`.

## Как добавить или заменить картинку

1. Положите исходник в `media/packs/` (упаковка) или `media/showcase/` (сцена, витрина). Имя латиницей: `box-x10.png`, `vitrina-apteka.png`. Чем больше исходник, тем чётче на ретине: для упаковки от 1200 px по длинной стороне, для широкой сцены от 2400 px.
2. Опишите её в `src/data/media.json` → `images`:
   - `alt` — что изображено, по-русски;
   - `bg` — `transparent` (вырезанная упаковка, PNG с прозрачностью), `white` (упаковка на белом фоне) или `photo` (сцена, не обрезается);
   - `roles` — где показывается: `card` (карточка товара), `cart` (корзина), `showcase` (широкая вставка).
3. Привяжите к товару: `sku` (точный артикул корзины, например `compact-100`) или `line` (вся линейка: `standard`, `compact`). Корзина ищет картинку так: артикул → линейка → нейтральная заглушка.
4. На странице: `<PackImg id="box-x10" />`, `<PackImg sku="compact-100" />` или `<PackImg id="vitrina-apteka" role="showcase" />`.

## Что делает сборщик (`scripts/build-images.mjs`)

- обрезает пустые поля вокруг упаковки и добавляет ровный отступ 4 %, чтобы все упаковки стояли одинаково;
- режет на ширины роли (`card`: 240–960, `cart`: 80–240, `showcase`: 480–1600, но не больше исходника) — это и есть ретина: браузер сам берёт 2× по `srcset` и `sizes`;
- сохраняет AVIF, WebP и запасной PNG/JPEG; в `<picture>` браузер берёт первый поддерживаемый формат;
- кладёт хэш содержимого в имя (`box-x10.e6d22e81-480.avif`), поэтому файлы кешируются на год (`.htaccess` в той же папке), а после замены исходника адрес меняется сам;
- проверяет каталог: битые ссылки, пустой `alt`, неизвестные роли останавливают сборку;
- пропускает неизменённые картинки, удаляет файлы прежних версий.

Ленивая загрузка включена по умолчанию (`loading="lazy"`); для картинки на первом экране — `<PackImg ... priority />`. Ширина и высота стоят в разметке, страница не прыгает при загрузке.

Упаковки на белом фоне (`bg: white`) на бирюзовой подложке выводятся с `mix-blend-mode: multiply`: белое сливается с фоном, без белого прямоугольника.

## Витрина (`showcase` в media.json)

Список мест, где стоят широкие сцены, чтобы их было легко найти и заменить. Сейчас: аптечная выкладка на `partnery.html` в блоке «Что даёт МЕНОРА-МЕД партнёру». Новые объединённые изображения для аптечной витрины добавляются так же: исходник в `media/showcase/`, запись в `images` с ролью `showcase`, строка в `showcase`.
